## 📌 سریزه او د سیسټم عمومي کتنه (System Overview)

د **درملو د عمده پلور او توزیع مدیریت سیسټم (WMDMS)** یو بشپړ، مسلکي او پرمختللی ویب غوښتنلیک (ERP) دی چې په ځانګړي ډول د افغانستان د درملو د لویو سټاکیسټانو، واردوونکو شرکتونو او عمده پلورونکو لپاره ډیزاین شوی دی.

دا سیسټم د عادي پرچون درملتونونو د سافټویرونو څخه بشپړ توپیر لري؛ دا د درملو د لوی حجم وارداتو، د ګودامونو کنټرول، د تاریخ انقضاء دقیق مدیریت (FEFO)، د درملتونونو د پورونو او کرډیټ محدودیتونو، د بازاریابانو (Salesmen/MR) حسابونو، او په افغانیو (**AFN / ؋**) د اصلي ګټې او لګښتونو د اتومات محاسبې لپاره جوړ شوی دی.

## 1. د سیسټم اساسي اصول او مالي معیارونه

| اصل | تشریح او قانون |
| :--- | :--- |
| **مالي اسعار (Currency)** | ټول حسابونه په افغانیو (**AFN / ؋**) دي. ټول رسیدونه، بلونه، لګښتونه او ګټه په افغانۍ سنجول کېږي. |
| **د انقضاء لومړیتوب (FEFO)** | هر کله چې درمل پلورل کېږي، سیسټم په اتومات ډول هغه بسته (Batch) مخکې کوي چې د ختمېدو نیټه یې تر ټولو نږدې وي. |
| **د پورونو کنټرول (Credit Limits)** | هر درملتون د پور یوه ټاکلې اندازه او وخت لري؛ که پور له حد واوړي، نوی بل نشي صادرېدای تر څو پخوانۍ پیسې ورنکړي. |
| **د ګټې دقیق حساب (Accurate COGS)** | د هر بل د پلور پر مهال د هغه ځانګړي بیچ د پېرود اصلي قیمت ثبتېږي ترڅو ریښتینې ګټه معلومه شي. |
| **د دوه اړخیز حسابونو خوندیتوب (Double Entry)** | هیڅ معامله په پټه نشي بدلېدای؛ ټول سټاک او مالي بدلونونه په تاریخي لیجر کې ثبتېږي. |

## 2. د کاروونکو رولونه او د لاسرسي کچې

سیسټم کاروونکي د دندو له مخې په مختلفو کچو ویشي ترڅو هیڅ کارمند بې له اجازې مهمو مالي او تنظیماتي برخو ته لاسرسی ونلري:

```
                          ┌──────────────────────────┐
                          │   عمومي مدیر (Super Admin)│
                          └─────────────┬────────────┘
                                        │
             ┌──────────────────────────┼──────────────────────────┐
             │                          │                          │
    ┌────────┴────────┐        ┌────────┴────────┐        ┌────────┴────────┐
    │  د پلور مدیر    │        │  د ګودام مسؤل   │        │ د محاسبې مسؤل   │
    │ (Sales Manager) │        │(Warehouse Head) │        │(Finance Officer)│
    └────────┬────────┘        └────────┬────────┘        └────────┬────────┘
             │                          │                          │
    ┌────────┴────────┐        ┌────────┴────────┐        ┌────────┴────────┐
    │ بازاریاب / وېشونکی│        │د سټاک مرستیال   │        │  د صندق تحویلدار │
    │ (Salesman / MR) │        │(Inventory Staff)│        │(Cashier/Counter)│
    └─────────────────┘        └─────────────────┘        └─────────────────┘
```

1. **عمومي مدیر (Super Admin / مالک):** ټول سیسټم ته لاسرسی، د ګټې او زیان لیدل، د کارمندانو جوړول او د بلونو لغوه کول.
2. **د پلور مدیر (Sales Manager):** د درملتونونو تایید، د پور د حد ټاکل، او د پلور د نرخونو کنټرول.
3. **د ګودام مسؤل (Warehouse Manager):** د راغلو مالونو تصدیق، نوي پېرود ثبتول، او د درملو د انقضاء څارنه.
4. **د محاسبې او مالي مسؤل (Accountant):** د پیسو راټولول، د شرکتونو د پورونو تادیه، د لګښتونو ثبت، او د راپورونو جوړول.
5. **بازاریاب او وېشونکی (Salesman / Field Rep):** په بازار کې د نویو فرمایشونو اخیستل او د درملتونونو څخه د تادیاتو وصولي.

## 3. د اصلي ډشبورډ او کنټرول مرکز

ډشبورډ (`/dashboard`) د ټول تجارت د کنټرول خونه ده چې په ژوندۍ بڼه لاندې معلومات ښيي:

- 📊 **د نن ورځې او میاشتې ټول پلور (Total Revenue):** ټول خرڅ شوي درمل په افغانیو.
- 💰 **ناخالصه او خالصه ګټه (Gross & Net Profit):** د لګښتونو څخه مخکې او وروسته ترلاسه شوې ریښتینې ګټه.
- 🚨 **د انقضاء خبرداری (Expiry Alerts):** هغه درمل چې په راتلونکو ۹۰ ورځو کې ختمېږي.
- 📦 **د کم سټاک خبرداری (Low Stock):** هغه درمل چې په ګودام کې یې اندازه له ټاکلې کچې کمه شوې وي.
- 👥 **د درملتونونو پاتې پورونه (Total Customer Receivables):** هغه پیسې چې په بازار کې په درملتونونو پاتې دي.
- 🏢 **د درمل جوړوونکو شرکتونو پورونه (Supplier Payables):** هغه پیسې چې ستاسو پر شرکت د عرضه کوونکو پاتې دي.
- 📈 **د پلور او پېرود میاشتنی ګراف:** د پېرود او پلور د بهیر مقایسه.

## 4. د درملو، فارمولونو او کټګوریو مدیریت

د درملو د ثبت او تنظیم لپاره له `/medicines` او `/categories` لارو څخه کار اخیستل کېږي:

### الف: د نوي درمل اضافه کول (Add New Medicine):
1. **د درملو نوم (Trade Name):** لکه `Amoxicillin 500mg Cap` یا `Panadol 500mg Tab`.
2. **جینریک فارمول (Generic Formula):** لکه `Amoxicillin Trihydrate` یا `Paracetamol`.
3. **کټګوري او درمل جوړوونکی (Category & Supplier):** د درملو ګروپ (لکه انټي بیوټیک، مسکن) او کمپنۍ وټاکئ.
4. **د بسته بندۍ واحدونه (Unit of Measure):** لکه بکس (Box)، پاکټ (Strip)، یا بوتل (Bottle).
5. **د ذخیره کولو شرایط (Storage Condition):** عادي تودوخه (Normal) یا یخ ګودام (Cold Chain 2°C - 8°C).
6. **د خطر کچه (Reorder Level):** لږ تر لږه اندازه چې کله ورسېږي سیسټم خبرداری ورکړي (لکه ۱۰ بکسونه).

## 5. د بستو او لومړۍ انقضاء لومړۍ پلور (FEFO Engine)

په عمده پلور کې تر ټولو مهم ټکی د درملو د ختمېدو د نیټې کنټرول دی. دا سیسټم په کلکه سره د **FEFO (First-Expire, First-Out)** قاعده عملي کوي:

```
[د پیرودونکو امر / نوی بل]
         │
         ▼
[د سیسټم د FEFO پلټنه په ګودام کې]
         │
 ┌───────┴─────────────────────────────────────────┐
 │ ۱. بسته B-101 (انقضاء: 2026-11) ➔ تر ټولو لومړی وځي │
 │ ۲. بسته B-102 (انقضاء: 2027-04) ➔ وروسته وځي     │
 │ ۳. بسته B-103 (انقضاء: 2027-12) ➔ په پای کې وځي  │
 └─────────────────────────────────────────────────┘
```

- **شین رنګ (خوندي سټاک):** د انقضاء نیټې ته یې له ۶ میاشتو زیات وخت پاتې دی.
- **ژېړ رنګ (منځنی خبرداری):** تر راتلونکو ۶ میاشتو پورې ختمېږي (باید ژر وپلورل شي).
- **سور رنګ (بېړنی حالت):** په ۹۰ ورځو کې ختمېږي یا ختم شوي دي (سیسټم یې په بلونو کې له خرڅلاو څخه منع کوي).

## 6. د ګودام او سټاک مدیریت

د ګودام د کنټرول مرکز په `/inventory` کې موقعیت لري:

### د سټاک د بدلون ډولونه (Stock Movements):
- **PURCHASE_IN (پېرود):** کله چې د کمپنۍ نوی مال ګودام ته داخل شي، سټاک ډېرېږي.
- **SALE_OUT (پلور):** کله چې درملتون ته بل صادر شي، سټاک په اتومات ډول کمیږي.
- **MANUAL_IN (افتتاحي سټاک):** د لومړي ځل لپاره د ګودام د شته درملو ثبتول.
- **DAMAGE_OUT (خراب شوي درمل):** هغه درمل چې مات شوي، تاریخ یې تېر شوی یا خراب شوي دي.
- **ADJUSTMENT (د سټاک تطبیق):** کله چې د ګودام فزیکي شمېرنه وشي او د سیسټم سره برابر شي.

> [!IMPORTANT]
> **قانون:** سیسټم هیڅکله منفي سټاک (Negative Stock) نه مني. که په ګودام کې درمل نه وي، د بل جوړولو اجازه نه ورکوي.

## 7. د تولیدي شرکتونو او عرضه کوونکو مدیریت

د درمل جوړوونکو شرکتونو او عمده واردوونکو لپاره ځانګړې برخه په `/suppliers` کې ده:

1. **د عرضه کوونکي پروفایل:** د شرکت نوم، د اړیکې شمیره، پته، او د افغانستان د عامې روغتیا وزارت لایسنس.
2. **مالي حساب (AP Ledger):** د کمپنۍ ټول پخواني پېرودونه او تادیه شوې پیسې په نیټه واره بڼه ښودل کېږي.
3. **د پورونو تصفیه (Supplier Payments):** کله چې تاسو شرکت ته پیسې استوئ (د صرافۍ، بانک یا نغدو له لارې)، په `/payments` کې واؤچر جوړېږي او د شرکت له حساب څخه منفي کېږي.

## 8. د درملو د پېرود او وارداتو ثبت

د نوي مال د داخلولو لپاره د پېرود پاڼې (`/purchases/new`) ته لاړ شئ:

1. **د شرکت انتخاب:** هغه عرضه کوونکی وټاکئ چې درمل یې را استولي دي.
2. **د بل شمیره او نیټه:** د شرکت اصلي بل نمبر (Invoice No) ولیکئ.
3. **د درملو اضافه کول:**
   - د درملو نوم وټاکئ.
   - د فابریکې بسته نمبر (Batch Number) دننه کړئ.
   - د تولید نیټه (Mfg Date) او د ختمېدو نیټه (Exp Date) وټاکئ.
   - د اخیستلو تعداد (Quantity) او د یو بکس د پېرود قیمت (Purchase Price) ولیکئ.
   - د عمده پلور نرخ (Trade Price) او پرچون نرخ (MRP) وټاکئ.
4. **تایید او ثبت:** د ثبت تڼۍ په کلیک کولو سره په فوري ډول:
   - درمل د اړوند بیچ سره ګودام ته اضافه کېږي.
   - د شرکت په حساب کې د پور اندازه اضافه کېږي.
   - په مالي راپورونو کې د پیرود لاګ ثبتېږي.

## 9. د درملتونونو او پیرودونکو مدیریت

په عمده پلور کې پیرودونکي عادي خلک نه، بلکې درملتونونه، کلینیکونه او روغتونونه دي (`/customers`):

### د درملتون ثبت او د پور د خوندیتوب سیستم:
- **د درملتون نوم او پته:** لکه `د کابل شفا درملتون - ده افغانان`.
- **د درملتون د مالک او ډاکټر معلومات:** د تلیفون شمیره او د درملتون لایسنس نمبر.
- **د پور اعظمي حد (Credit Limit):** د بېلګې په توګه: `۵۰۰,۰۰۰ افغانۍ`. که د درملتون پور له دې کچې واوړي، سیسټم اتومات ډول بل بلاک کوي.
- **د پور اعظمي موده (Overdue Threshold):** د بیلګې په توګه `۳۰ ورځې`. که پخوانۍ پیسې په ۳۰ ورځو کې رانشي، تر هغې نوی مال نه ورکول کېږي تر څو حساب تصفیه نکړي.
- **د حساب تاریخچه (Customer Ledger):** په یوه کلیک سره د هر درملتون د څو کلونو بلونه، تادیات او پاتې حساب لیدلای او چاپولای شئ.

## 10. د عمده پلور، آرډر او بل جوړولو پروسه

د پلور نوې پاڼه (`/sales/new`) په خورا چټکۍ او دقت سره د سلګونو قلمونو د ثبتولو توان لري:

```
[۱. د درملتون انتخاب] ➔ [۲. د بازاریاب ټاکل] ➔ [۳. د درملو او تعداد ټاکل]
                                                           │
[۶. د بل او چلاني چاپ] ◄── [۵. د بل رسمي تایید] ◄── [۴. اتومات FEFO بیچ او نرخ]
```

### عملي مرحلې:
1. **د درملتون انتخاب:** درملتون وټاکئ (سیسټم فورا د هغه پخوانی پور او د کرډیټ حالت ښيي).
2. **د بازاریاب انتخاب:** هغه استازی چې آرډر یې راوړی وټاکئ.
3. **د درملو لټون:** د درملو نوم ولیکئ، سیسټم د خورا نږدې انقضاء بیچ په اتومات ډول وړاندیز کوي.
4. **تعداد او تخفیف:** د بکسونو تعداد ولیکئ، او که تخفیف ورکوئ فیصدي یا ټاکلې افغانۍ ولیکئ.
5. **د کرډیټ اتومات چیک:** که چیرې د پیرودونکي پور له حد زیات نه وي، بل په بریا سره صادرېږي.
6. **د ګټې ثبت:** د پلور پر مهال د هر درمل اصلي خرید نرخ د بل تر شا خوندي کېږي ترڅو د ګټې حساب دقیق پاتې شي.

## 11. د رسمي بلونو او د موټر د تحویلۍ چلانونو چاپ

د عمده پلور د هر بل لپاره دوه ډوله رسمي چاپي سندونه شتون لري (`/invoices/[id]`):

### ۱. د عمده پلور رسمي مالیاتي بل (Tax Invoice):
- د درملو نومونه، بسته نمبر (Batch)، د انقضاء نیټه، تعداد، د یو بکس نرخ، تخفیف، او ټولټال قیمت په افغانیو.
- د درملتون پخوانی پور، د اوسني بل قیمت، او نوی ټولټال پاتې پور.

### ۲. د ډرایور د تحویلۍ چلاني (Delivery Challan):
- په دې سند کې **هیڅ ډول مالي نرخونه نه ښکاري**؛ یوازې د کارتنونو او بکسونو تعداد، د درملو نومونه او د بیچ شمیرې ښکاري ترڅو موټر چلوونکی او ډلیوري کونکی یې په اسانۍ سره درملتون ته تسلیم او لاسلیک ترې واخلي.

## 12. د پیسو راټولول او د رسیداتو ثبت

د پیسو ترلاسه کول په `/payments` برخه کې ترسره کېږي:

### د پیسو د راټولولو اصول (FIFO Debt Settlement):
- کله چې بازاریاب د یوه درملتون څخه `۱۰۰,۰۰۰ افغانۍ` راوړي، تاسو یې په سیسټم کې د پیرودونکي د رسید په بڼه ثبتوئ.
- **اتومات تصفیه (FIFO):** سیسټم دا پیسې تر ټولو لومړی د پیرودونکي پر خورا زاړه پور (Oldest Overdue Invoice) حسابوي او هغه خلاصوي، او پاتې برخه پر نویو بلونو ویشي.
- **د تادیې بڼې:**
  - نغدې پیسې (Cash)
  - د صرافۍ حواله (Sarafi / Hawala)
  - بانکي انتقال (Bank Transfer)
  - چک (Cheque)
- **د رسید چاپ:** پیرودونکي ته په فوري ډول د پیسو د رسید رسمي سند (Money Receipt) چاپ کړئ.

## 13. د وېشونکو او بازاریابانو مدیریت او حسابونه

د بازاریابانو (Medical Reps / Salesmen) مدیریت په `/distributors` کې کېږي:

- **د بازاریاب بشپړ پروفایل:** د وېشونکي نوم، اړیکه، د فعالیت سیمه (Zone/Territory) او د کمیشن سلنه.
- **د بازاریاب کوکپیټ (Salesman Cockpit):** په یوه پاڼه کې ښيي چې اړوند بازاریاب څومره درمل پلورلي، څومره پیسې یې شرکت ته راوړې، او په کومو درملتونونو یې څومره پیسې پاتې دي.
- **د وصولۍ راپور (Recovery Report):** د ورځو او میاشتو په تفکیک سره د بازاریاب د نغدو او غیر نغدو وصولیو دقیق حساب.

## 14. د سوداګرۍ عملیاتي او ورځني لګښتونه

د اصلي خالصې ګټې د معلومولو لپاره باید ټول مصارف په `/expenses` کې ثبت شي. په سیسټم کې ۵ معیاري کټګورۍ شتون لري:

```
┌─────────────────────────────────────────────────────────────┐
│                 د سوداګرۍ عملیاتي لګښتونه                   │
├─────────────────────────────────────────────────────────────┤
│ ۱. د ګودام او دفتر کرایه (EXP-RENT)                        │
│ ۲. د ورځني دفتر مصارف لکه چای، ډوډۍ او متفرقه (EXP-DAILY)  │
│ ۳. د بازاریابانو او کارمندانو معاشونه او لګښت (EXP-SALESMAN)│
│ ۴. د میلمنو او سوداګریزو ناستو لګښتونه (EXP-VISITOR)        │
│ ۵. د ډاکټرانو او بازارموندنې ځانګړي لګښتونه (EXP-DOC-MKT)   │
└─────────────────────────────────────────────────────────────┘
```

هر لګښت خپل ځانګړی واؤچر نمبر (`EXP-YYYY-XXXXX`) لري چې د تاریخ، لګښت کوونکي او پیسو په اندازه سره ثبت او د چاپ وړ دی.

## 15. د ناخالصې او خالصې ګټې تحلیل او مالي راپورونه

د مالي ګټې استخبارات په `/profit` کې په خورا شفاف ډول ښودل کېږي:

### مالي حسابي فورمولونه:
$$\text{ټول پلور (Revenue)} - \text{د درملو د پېرود اصل قیمت (Historical COGS)} = \text{ناخالصه ګټه (Gross Profit)}$$

$$\text{ناخالصه ګټه (Gross Profit)} - \text{ټول عملیاتي لګښتونه (Expenses)} = \text{خالصه ګټه (Net Profit)}$$

### په سیسټم کې د ګټې بېلابېل لیدونه:
- **د درملو له مخې ګټه:** کوم درمل تاسو ته تر ټولو زیاته ګټه راوړي؟
- **د بازاریابانو له مخې ګټه:** کوم استازی ستاسو د شرکت لپاره ګټور دی؟
- **د شرکتونو له مخې ګټه:** د کوم تولیدي شرکت درمل لوړه ګټه لري؟
- **له لګښت پرته د ګټې روښانه تفکیک:** د ناخالصې ګټې او د لګښتونو له وضع کولو وروسته خالصې ګټې واضح توپیر.

## 18. د ورځني کار منظم مهالوېش (Daily Routine)

د شرکت د ښه مدیریت لپاره سپارښتنه کېږي چې ستاسو کارمندان لاندې ورځنی پلان عملي کړي:

### ۱. د سهار چارې (۰۸:۰۰ تر ۰۹:۰۰ سهار):
1. د ډشبورډ کتل او د انقضاء او کم سټاک د خبرداریو ارزول.
2. بازاریابانو ته د هغو درملتونونو لیست سپارل چې پور یې له وخت اوښتی وي.
3. د ورځې د تقسیماتو لپاره د موجود سټاک تاییدول.

### ۲. د ورځې په جریان کې:
1. ګودام ته د رارسېدلو نویو پېرودونو سمدستي ثبتول له کره بیچ او انقضاء سره.
2. د بازاریابانو د نویو فرمایشونو ثبتول او د درملتونونو د پور د حد څارل.
3. د تحویلۍ د چلانونو چاپ او ډرایورانو ته د درملو سپارل.

### ۳. د ماښام حساب او بندول (۰۴:۰۰ تر ۰۵:۰۰ ماښام):
1. د بازاریابانو او صندق څخه د نغدو او صرافۍ د پیسو ترلاسه کول او په `/payments` کې د رسیداتو ثبت.
2. د ورځې د لګښتونو (کرایه، ډوډۍ، د ډاکټرانو مصارف) ثبتول.
3. د ډشبورډ پر مخ د نن ورځې د ګټې او ټولیز پلور ارقام ارزول.

## 19. د معلوماتو شاتړ او بیا رغونه (Backup & Recovery)

- **لاسي شاتړ (Manual Export):** هره اونۍ یو ځل له `/reports` څخه د ټولو درملو، پیرودونکو او لېجرونو CSV فایلونه د خوندیتوب لپاره په کمپیوټر کې وساتئ.
- **د بیړني حالت لارښود:** د ډیټابیس د بیا رغولو او تفصیلي تخنیکي لارښود لپاره [`docs/backup-recovery.md`](./docs/backup-recovery.md) ولولئ.

## 20. پرله پسې پوښتنې او حل لارې (FAQ)

### پوښتنه ۱: که یو درمل په دوو مختلفو نرخونو اخیستل شوی وي، د پلور پر مهال کوم نرخ عملي کېږي؟
**ځواب:** سیسټم د **FEFO** پر بنسټ کار کوي. هغه بسته چې ژر ختمېږي لومړۍ پلورل کېږي او د هغې بستې اصلي د پېرود نرخ به د ګټې په حساب کې وضع کېږي.

### پوښتنه ۲: که د یوه درملتون پور له حد اوښتی وي او مالک وغواړي استثنايي بل ورکړي، څه باید وکړي؟
**ځواب:** د پلور مدیر یا عمومي مدیر کولی شي د درملتون پاڼې (`/customers/[id]/edit`) ته لاړ شي او د هغه د پور حد (Credit Limit) په موقتي ډول لوړ کړي.

### پوښتنه ۳: ولې یو درمل په بل کې نه ښکاري یا پلورل کېږي نه؟
**ځواب:** دوه لاملونه شتون لري:
۱. په ګودام کې یې سټاک صفر دی.
۲. د درملو د انقضاء نیټه پای ته رسېدلې ده او سیسټم د ناروغ د روغتیا او قانوني مسؤلیت له امله د پلور اجازه نه ورکوي.

### پوښتنه ۴: څنګه د موټر چلوونکي لپاره پرته له قیمتونو بل چاپ کړو؟
**ځواب:** د بل په پاڼه کې د **Print Delivery Challan** (د تحویلۍ چلاني) تڼۍ ووهئ. په دې سند کې یوازې درمل، کارتنونه او بیچ نمبرونه ښکاري او مالي ارقام پټ وي.
